Changelog#

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

Unreleased#

2.0.0 - 2026-11-01#

Changed#

  • sundgren graph draws where branches stand against a base branch: a vertical map, newest on top, routed like a circuit board, with the base as the reference line and local and remote refs as twin lanes. It prints sundgren.graph/3 JSON, or Unicode with --format text. It replaces sundgren.graph/1 and the REV and -n arguments.

  • VS Code: sundgren: Show History shows that map, and opens from Containment with its base and target.

Added#

  • sundgren graph picks branches with --show local|recent|mine|like, --branches, --pin and --hide, and the page with --commits, --since and --until.

  • VS Code History panel: a time axis, short hashes, whole commit messages on hover, a branch list to tick, author and date (calendar) filters, folded runs of commits, and Load older.

1.1.1 - 2026-10-31#

Added#

  • The VS Code extension is on the Marketplace, as a preview.

Fixed#

  • Code in the panels and the docs shows as typed: the fonts’ ligatures no longer draw -> as an arrow or >= as ≥.

1.1.0 - 2026-10-31#

Added#

  • sundgren contain A B --base REV (prototype) measures how much of the work each branch added since it left the base is in the other, by content: exact and edited (fuzzy) lines. Lines that are only a comment are left out (--comments count keeps them); --lines lists every line and where it was found.

  • In Python, Rust and C files, sundgren reads the code: containment per function and class, with where each went in the other branch. sundgren outline FILE shows what it reads.

  • VS Code: sundgren: Show Containment compares every branch with a target, with sync, worktree and uncommitted-changes badges; Inspect shows a branch’s edited and missing lines next to the target’s; sundgren: Show Outline shows a file as sundgren reads it.

  • Docs: Features and Containment pages; the demos work like the panels, on data the docs build makes with the current sundgren.

Changed#

  • One look for the panels and the docs site (style/), with the Inter and JetBrains Mono fonts.

1.0.0 - 2026-10-31#

Changed#

  • sundgren is now a git history visualizer. The coverage delta tool (sundgren run, diff, presets, ingest) and the extension’s “pluck a test” are removed.

Added#

  • sundgren graph [REV] prints the history of a revision laid out as a graph, as sundgren.graph/1 JSON.

  • VS Code: sundgren: Show History shows a branch’s history as a graph in a panel.

  • Docs: a History graph page with a live demo, and a Development menu listing the previews of main and of every open pull request.

2026, Axel E. Andersson
