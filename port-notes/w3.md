# Port notes: w3

Decisions and test changes, folded into DECISIONS.md by main at merge.

## Decisions

- pyclasses honour `dataclasses.asdict`/`astuple`/`fields`/`replace`: each gets a
  `__dataclass_fields__` class attribute built with `dataclasses.make_dataclass` (W1's shared
  helper). Keeps `asdict(Stats())` in test_rollup and `asdict(node.stats)` in json_report
  unchanged. A unit test runs those helpers on a pyclass so a dataclasses change fails loudly.
- File paths in `FileDelta`, `TreeNode` and warning messages are `PyText`, because a line map
  can carry a surrogate-escaped patch path into the delta. They round-trip to the same Python
  str as in the prototype.
- Branch ids: `line N` refs and natural sort use Unicode decimal digits, as Python's `\d` and
  `int()` do. The one difference: a `line N` whose N doesn't fit in i64 is treated as unmapped.
  The prototype would shift it like any other line.
- `diff` (Rust) takes the symbolizer lookup as a callback. The binding reads the live
  `symbols._REGISTRY` through `get_symbolizer` on every call, so monkeypatching still works.
- Delta, FileDelta and TreeNode cache their tuple fields on first access, so `d.files is d.files`.

## Join (`crates/sundgren-join`, M3 prep)

- `FileCoverage` has no source sha, so the caller passes the sha256 of the measured source per
  file (`Measured.source_sha256`). On a mismatch the file gets no facts and an
  `ir_source_mismatch` warning.
- A fact's lines are the node's counted lines: the body for functions and closures (the whole
  span for a one-liner), the whole span otherwise. Nested nodes' lines count too, as in the
  prototype's function status. Run 0 decides hit/missed.
- Branches (no L2 yet) go to the innermost node whose span covers the branch line, and only to
  that node.
- Status precedence: `flaky` (any counted line differs between repeats), then `unmeasured` (no
  executable line), then `covered`, `uncovered` or `partial`.
- Line ambiguity: `shared` lists executable lines that also lie in a node that is neither an
  ancestor nor a descendant (e.g. two lambdas on one line). `granularity` is passed in by the
  caller; lcov is `line`.
- lcov `FN` records attach to callable nodes via `rollup::match_spans` (now public): qualified
  name first, then largest line overlap. `FunctionMatch.by` records which. coverage.py's
  `outer.inner` matches the IR's `outer.<locals>.inner` by overlap.
- `tests` is always None until per-test coverage exists.
