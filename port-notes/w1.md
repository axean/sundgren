# Port notes: w1

Decisions and test changes, folded into DECISIONS.md by main at merge.

## model

- `LineNo` is i64 and counts are i128 (Python `int()` takes negatives and 2^64 - 1 counters). Values
  outside i128 raise, where Python would keep them.
- `sundgren_core::pyint::py_int` follows `int(str)`: whitespace, sign, `_` between digits, and
  decimal digits of any script (table from Unicode 15.0, Python 3.12; digits added in later
  Unicode versions are rejected). A line number outside i64 is a malformed record, where Python
  kept it.
- All maps are `BTreeMap`, so Python sees dicts in sorted order. Every producer sorted already.
- The classes are frozen pyclasses wrapping the Rust value. Dict and tuple fields are converted on
  first access and cached. Mutating such a dict changes neither the object nor its equality.
- Shared helper `sundgren-py/src/pyclass.rs` (`dataclass!` macro) gives `__dataclass_fields__`,
  `__match_args__`, the dataclass repr and `__reduce__`, so `dataclasses.asdict/astuple/fields/
  replace/is_dataclass`, copy and pickle work. Needs pyo3's `multiple-pymethods` feature.
- `hash(FileCoverage)` says `unhashable type: 'sundgren.core.model.FileCoverage'` (module-qualified).
- `LineStatus` is a pyclass enum with `.name`/`.value` and the Enum repr, but no `LineStatus("hit")`
  lookup or iteration. Nothing used either.
- New test file `tests/unit/test_model.py` (dataclass helpers, repr, eq/hash/order, copy, pickle).

## normalize, hashing

- `normalize::realpath` ports Python 3.11/3.12's `posixpath.realpath` (the recursive
  `_joinrealpath`). 3.13 changed only symlink-loop handling (it keeps resolving after the loop).
  Checked against `os.path.realpath` on 3.12: 271200 paths over symlinks, loops, dangling links,
  `..`, `//`, relative and absolute, 0 differences. A non-UTF-8 result is converted lossily.
- `sha256_file` raises pyo3's OSError subclass; the message reads "No such file or directory
  (os error 2)" rather than "[Errno 2] ...: 'path'".

## lcov

- Debug logs go through a `&mut dyn FnMut(String)` sink; the binding forwards to the Python
  logger only when it is enabled for DEBUG. The ValueError message uses Python's own `repr`.
- Checked against the 0.1.2 parser on 100000 random tracefiles (all record kinds, bad numbers,
  Unicode digits, odd separators, BOM, CRLF): same snapshot, dump, error and debug messages.
- `LcovIngestor` is a small pyclass.

## junit

- XML is parsed with roxmltree (DTDs allowed, for internal entities) instead of expat. The text
  after "malformed JUnit XML: " is roxmltree's error, so a `junit_unreadable` warning for a
  malformed file reads differently. Everything else matches.
- Checked against the 0.1.2 parser on 120000 random documents (namespaces, entities, DOCTYPE,
  CDATA, nesting, truncation): same outcomes, same accept/reject, same "not JUnit XML" messages
  and debug logs.

## differential tool

- `uv run python tools/differential.py` runs 0.1.2 (uvx) and the working tree on 239 cases from
  tests/fixtures: `ingest` of every lcov file (with and without `--root`); `diff` on both
  shed_py_runs pairs with their patch and JUnit under every output option (json/text, `--full`,
  `--counts`), with roots, without a patch; both pairs against all 24 patches (incl. bad.patch
  and the unit patches); every JUnit fixture on one or both sides, a missing and an unreadable
  JUnit file; a missing lcov; all 25 lcov fixture pairs, with and without `--strip-prefix`.
- Compares stdout, stderr and exit code byte for byte, ignoring only `meta.created_utc` and
  `meta.sundgren_version`. `junit/unreadable` is a known difference (expat vs roxmltree text).

## CI

- New `rust` job in ci.yml: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets
  --locked -- -D warnings`, `cargo test --workspace --exclude sundgren-py --locked` on stable,
  with Swatinem/rust-cache. sundgren-py is excluded from `cargo test` because its test harness
  would link libpython; pytest covers it.
- The other jobs build the extension in `uv sync` (maturin) with the runner's Rust (stable, or
  1.99.1 where pinned). No changes needed.
