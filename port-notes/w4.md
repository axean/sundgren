# Port notes: w4

Decisions and test changes, folded into DECISIONS.md by main at merge.

## Decisions (agreed with main)

- `default_python` logic is Rust and takes a `which` hook. The binding passes Python's
  `shutil.which`, looked up at call time, so `test_template.py` still monkeypatches it.
- `presets._BUILTINS` and `selectors._REGISTRY` stay dicts in their .py modules. The bindings read
  them by module attribute at every call, so tests that replace or patch them still work.
- TOML is decoded by Python's `tomllib` behind the `presets::TomlLoader` trait; Rust validates the
  decoded tables. Accepted input and decode errors stay tomllib's. A native binary can plug in the
  `toml` crate later.
- argparse stays in `cli.py` for M1. Rust owns every command handler and gets the parsed args as one
  plain Rust struct.
- `Preset` is a frozen pyclass with W1's `dataclass!` helper (`dataclasses.replace` works). Like the
  dataclass it isn't hashable (it holds a dict); the `TypeError` names the class, not `dict`.

## Port details

- `shlex.split`/`quote`/`join` are ported (`sundgren_run::shlex`), fuzzed against Python on 200k
  inputs.
- `{name!r}` in messages uses `pyfmt::repr_str`. Unassigned code points count as printable there
  (Python escapes them); everything else matches `str.isprintable`.
- `tempfile.mkdtemp` is ported: same candidate dirs (TMPDIR, TEMP, TMP, /tmp, /var/tmp, /usr/tmp,
  cwd), 0700, `sundgren-` plus 8 chars. `tempfile.tempdir` set from Python is not honoured.
- `RunFailure` is defined by Python source run from the binding, so its `(message, log_tail)`
  constructor and `str()` match. The other exceptions are `create_exception!` classes with the same
  bases (`PresetError(ValueError)`, `GitError(RuntimeError)`, `BadRefError(GitError)`,
  `PatchApplyError(Exception)`).
- Selection test ids are Rust `String`s: a test path with non-UTF-8 bytes (a surrogate in Python)
  raises instead of reaching argv.
- Display commands quote tokens outside `[\w@%+=:,./{}-]`; Rust's `is_alphanumeric` stands in for
  Python's Unicode `\w`, which differs only on combining marks.
- A command that can't start logs `[Errno N] strerror: 'argv0'`. Python names the cwd instead
  when the chdir failed; Rust can't tell those apart.
- Selectors get a fresh `Patch` object equal to the caller's (the patch crosses as a Rust value).
