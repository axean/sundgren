sundgren#

Given a repo, a base ref and a patch, usually one that changes tests, sundgren answers: what happened to source coverage because of this patch? It runs a coverage command on the base tree and on the patched tree, diffs the two lcov files with line numbers mapped through the patch, and reports the lines, branches, functions and test outcomes that changed.

Install it from PyPI. How it works explains the steps, and the reference lists every option, preset key, exit code and warning.

Note

Each example below is a small project, a patch and the command. The docs tests rerun the command and compare its output with the files shown here, and the graphic is drawn from the recorded JSON report.

Python: skipping a test#

Project#

shed/calc.py#
# shed/calc.py
def add(a, b):
    return a + b

def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("b is zero")
    return a / b

def classify(n):
    if n < 0:
        return "neg"
    elif n == 0:
        return "zero"
    return "pos"
tests/test_calc.py#
# tests/test_calc.py
import pytest
from shed.calc import add, divide, classify

def test_add():
    assert add(1, 2) == 3

def test_divide():
    assert divide(6, 3) == 2
    with pytest.raises(ZeroDivisionError):
        divide(1, 0)

@pytest.mark.parametrize("n,expected", [(-1, "neg"), (0, "zero"), (5, "pos")])
def test_classify(n, expected):
    assert classify(n) == expected
.coveragerc#
[run]
source = shed
branch = True
pyproject.toml#
[tool.pytest.ini_options]
pythonpath = ["."]

Patch#

The patch skips test_divide, the only test that calls divide.

skip_divide.patch#
diff --git a/tests/test_calc.py b/tests/test_calc.py
index 4b4cae3..7de0c91 100644
--- a/tests/test_calc.py
+++ b/tests/test_calc.py
@@ -5,6 +5,7 @@ from shed.calc import add, divide, classify
 def test_add():
     assert add(1, 2) == 3
 
+@pytest.mark.skip
 def test_divide():
     assert divide(6, 3) == 2
     with pytest.raises(ZeroDivisionError):

Command#

Run in the project’s git repo, with the patch file at its root. The pytest preset is picked from pyproject.toml.

sundgren run --patch skip_divide.patch --format json --full -o report.json
sundgren run --patch skip_divide.patch --format text -o report.txt

Rust: ignoring a test#

Project#

src/lib.rs#
pub fn divide(a: i64, b: i64) -> Result<i64, &'static str> {
    if b == 0 {
        return Err("b is zero");
    }
    Ok(a / b)
}

pub fn classify(n: i64) -> &'static str {
    if n < 0 {
        "neg"
    } else if n == 0 {
        "zero"
    } else {
        "pos"
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_divide() {
        assert_eq!(divide(6, 3), Ok(2));
        assert_eq!(divide(1, 0), Err("b is zero"));
    }

    #[test]
    fn test_classify() {
        assert_eq!(classify(-1), "neg");
        assert_eq!(classify(0), "zero");
        assert_eq!(classify(5), "pos");
    }
}

Patch#

The patch marks test_divide, the only test that calls divide, with #[ignore].

ignore_divide.patch#
diff --git a/src/lib.rs b/src/lib.rs
index 3c09d9c..34314cd 100644
--- a/src/lib.rs
+++ b/src/lib.rs
@@ -20,6 +20,7 @@ mod tests {
     use super::*;
 
     #[test]
+    #[ignore]
     fn test_divide() {
         assert_eq!(divide(6, 3), Ok(2));
         assert_eq!(divide(1, 0), Err("b is zero"));

Command#

Run in the project’s git repo, with the patch file at its root.

sundgren run --patch ignore_divide.patch --preset cargo-tarpaulin --format json --full -o report.json
sundgren run --patch ignore_divide.patch --preset cargo-tarpaulin --format text -o report.txt

The recording was made with the rustc and cargo-tarpaulin versions pinned in the example’s manifest. Other versions can change the hit counts.

example.toml#
language = "rust"
patch = "ignore_divide.patch"
outputs = ["report.json", "report.txt"]
requires = [
    { run = "rustc --version", expect = "rustc 1.99.1 " },
    { run = "cargo tarpaulin --version", expect = "tarpaulin 0.37.5\n" },
]
