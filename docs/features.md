# Features

What sundgren does so far. Each page has a live demo of the VS Code panel, on a made-up repository.

[History graph](history.md)
: The history of a branch as a graph: one lane per line of work, coloured per branch, with its
  refs, subjects, authors and dates. **sundgren: Show History** in VS Code, `sundgren graph` on
  the command line.

[Containment](containment.md) (prototype)
: How much of each branch's work is already in another branch, and the other way round, by
  content rather than ancestry. It finds extractions, rebased copies and overlapping work.
  **sundgren: Show Containment** in VS Code, `sundgren contain` on the command line.
