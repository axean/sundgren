# Development

sundgren is developed in the open: every pull request gets its own preview of these docs, and
`main` has one too, so you can see what is being worked on before it is released.

<div id="sg-environments">

- [Live site](https://axean.github.io/sundgren/): the latest release
- [main](https://axean.github.io/sundgren/main/): the preview of main

</div>

The **Development** menu at the top of every page lists the same, and opens the page you are on in
that version. The source, issues and pull requests are on
[GitHub](https://github.com/axean/sundgren).
